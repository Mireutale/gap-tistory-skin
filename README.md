# Gap — 티스토리 스킨

Lovable 영감의 크림/차콜 팔레트 기반 에디토리얼 티스토리 스킨.

- **Pretendard Variable** 폰트
- **라이트 / 다크 / 시스템 자동** 테마 (FOUC 없음)
- **highlight.js** 코드 블록 (30+ 언어)
- **KaTeX** LaTeX 수식 렌더링 (`$인라인$`, `$$블록$$`, `\(...\)`, `\[...\]`)
- 글 목록 · 글 상세 · 카테고리 · 검색 · 방명록 · 공지 · 태그 · 소개 페이지 전체 지원
- 모바일 320px ~ 데스크톱 1440px 반응형

## 설치 방법

티스토리 관리자 → **꾸미기 → 스킨 편집** 으로 이동합니다.

1. **HTML 편집** 탭에 `skin.html` 전체 내용 붙여넣기
2. **CSS 편집** 탭에 `style.css` 전체 내용 붙여넣기
3. **저장**

이미지(아이콘)는 HTML에 인라인 SVG로 포함되어 있어 별도 파일 업로드가 필요 없습니다.

## 사용자 설정 변수

관리자 → 꾸미기 → 스킨 → 스킨 설정에서 조절 가능:

| 변수 | 설명 | 기본값 |
|------|------|--------|
| 테마 모드 | auto / light / dark | auto |
| 글 목록 썸네일 표시 | 체크 시 썸네일 표시 | 켜짐 |
| 목록에서 카테고리 표시 | 체크 시 카테고리 칩 표시 | 켜짐 |
| 푸터 문구 | 푸터에 표시할 텍스트 | © 블로그명. All rights reserved. |
