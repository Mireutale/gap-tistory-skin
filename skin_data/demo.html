2026.05.21 조회 142 댓글 4

티스토리 스킨은 단일 skin.html 파일에 모든 페이지 로직을 담는 구조다. 서버가 현재 URL을 기반으로 <s_index>, <s_article_rep> 등의 영역 태그를 활성화하거나 비활성화한다.

영역 태그의 동작 방식

티스토리 서버는 요청 URL에 따라 관련 <s_*> 블록만 렌더링하고 나머지는 제거한다. 홈이면 <s_index>만, 글 상세이면 <s_article_rep>만 남는다.

핵심 치환자

  • [##_title_##] — 블로그 제목
  • [##_article_rep_title_##] — 글 제목
  • [##_article_rep_desc_##] — 글 본문 HTML
  • [##_category_list_##] — 카테고리 트리

function applyTheme(t) {
  const dark = t === 'dark' ||
    (t === 'auto' && matchMedia('(prefers-color-scheme: dark)').matches);
  document.documentElement.dataset.theme = dark ? 'dark' : 'light';
}
CSS 변수를 토큰 단위로 정의해두면 다크모드 전환을 단 한 블록으로 처리할 수 있다. 모든 컴포넌트가 토큰을 참조하기 때문에 토큰 값만 바꾸면 전체가 바뀐다.

실제 적용 결과는 기대 이상으로 만족스러웠다. Pretendard Variable 폰트가 한글 가독성을 크게 높여주었고, 크림 배경색이 장시간 읽기에 눈을 덜 피로하게 만들었다.
